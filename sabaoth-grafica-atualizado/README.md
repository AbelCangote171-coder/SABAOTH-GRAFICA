# SABAOTH Gráfica — Landing page

Landing page estática feita com HTML, CSS e JavaScript, sem backend.

## Estrutura
- `index.html` — conteúdo e estrutura.
- `styles.css` — layout, cores, galeria e responsividade.
- `script.js` — links WhatsApp, menu mobile, filtros e lightbox.
- `assets/images/sabaoth-logo.svg` — logótipo vetorial fornecido.
- `assets/images/portfolio/` — imagens fornecidas para a galeria.

## Executar localmente
Abre `index.html` no navegador ou usa a extensão Live Server no VS Code.

## WhatsApp
O número está configurado em `script.js` como `244951940041`. Os links abrem o WhatsApp com mensagens pré-preenchidas; o visitante confirma o envio.

## Publicar
Podes publicar a pasta do projecto num serviço de alojamento estático, como Netlify, Vercel ou GitHub Pages. Não é necessário backend.

## Imagem do hero
A imagem de fundo do hero é carregada de uma URL do Unsplash. É necessária ligação à Internet para carregar essa imagem e as fontes Google Fonts. As imagens do portfólio e o logótipo estão incluídos localmente no projecto.
